# CREDITS — `daily-music-2026-08-22-sunna-offbeat`

*The companion credits file. Every dedication below is measured in code against the
500-character cap, never eyeballed. ⛔ **These names appear HERE and in the
per-song `## DEDICATION` block ONLY — never in a music prompt, exclude field, lyric
or title.** A name in a generator-facing field is an instruction to imitate; a name
here is a debt paid. Proved by `credit_sweep.py`: 0 leaks across 4 fields x 24 songs.*

**Honesty clause, both ways:** these are generated tracks, **not samples**. Where a
figure of sound was asked for by name, we name the player who made it — *we asked for
this figure, so we name him* — never *"contains a sample of."*
