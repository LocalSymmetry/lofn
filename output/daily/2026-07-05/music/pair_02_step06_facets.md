# Pair 02 Step 06 - Isolated Facets

1. The listener can name the place: hands at a kitchen table measuring quiet into a small wooden model.
2. The danger is concrete: rest can feel like trespass when the nervous system still expects work.
3. The hook is singable without becoming a slogan: `make the rest house real`.
4. The form is unmistakably this pair's: four-corner lullaby: each corner changes the definition of rest.
5. The sound has one ownable device: brushed snare moves like a pencil on wood; chorus adds four small bell tones, one per corner.
6. Pair-bleed gate: compare against the other five selected songs; if section map or sentence skeleton matches, this pair fails.
