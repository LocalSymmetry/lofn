### ⭐ THE RHYME DEBT DECLARATION (required of every pair, stated here up front)

*Stripping end-rhyme is legitimate; **removal is a debt.** A pair that strips rhyme must name what returns in
its place. A brief written entirely in negatives produces a lecture no matter how good the concept is.*

| pair | rhyme posture | **what returns in its place** |
|---|---|---|
| P01 | end-rhyme sparse by design | **the vowel braid** — one vowel carried across consecutive line-ends, plus a single-line refrain framing the catalogue. The return is in the mouth, not the spelling. |
| P02 | **full end-rhyme, unapologetic** | nothing stripped. Byte-identical 4-line chorus ×3, gang chant ≥4 returns. **No debt.** |
| P03 | end-rhyme displaced | **half-line echo** — the back half of each hook line repeats the front half's rhythm with one word swapped, every time. |
| P04 | end-rhyme replaced by head-rhyme | **consonant hammer** — the plosive cluster returns at line-**heads**, so the return arrives early. Plus a 2-line chorus ×4. |
| P05 | **zero rhyme for eight lines at a time** — the largest debt in the run | **paid in full and immediately** by a 4-line **byte-identical** chorus. The contrast *is* the return. ⭐ **No justification note is to be written about this chorus.** |
| P06 | end-rhyme forbidden | **rebound rhyme** — the rhyme lands inside the bar on beat 3, every couplet, sixteen times. |

**Every pair has a positive return device. Zero pairs ship a naked subtraction.**
