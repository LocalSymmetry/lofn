## THE ACCESSIBILITY FLOOR IS THE ART (declared, non-negotiable — NORMAN presides)

This pair renders the founder's law AS craft, not despite it:

- **Interaction states are GEOMETRY changes, not glow.** The five button states differ in *silhouette and engraved edge*, separable in pure greyscale by a thumb: `rest` (single hairline keyline, flush face) → `hover` (DOUBLED keyline + raised bevel) → `focus/selected` (OUTBOARD bracket-lattice ring, the kintsugi lattice doing double duty) → `pressed/active` (INSET / de-bossed, bevel inverted, one molten bead in the seam) → `visited` (cooled-bronze, engraving filled flat, corners softened). This is the seam-biography 5-state machine (dormant → shimmer → lit-lattice → molten pour → cooled bronze) mapped onto real UI states, so P3 and P4 speak one language. **Cooled-bronze also serves DISABLED** — warm, never a harsh grey-out, never a shame-state.
- **Badge glyphs are three distinct SHAPES, greyscale-legible:** `FUN` = radiant **sunburst** · `SPARK` = single-tailed **spark-seed** · `KILL` = asymmetric **cooled slag**. Shape carries the verdict; the engraved word only confirms it; a warm→cool temperature runs across the trio as a *redundant* second cue. Never color alone.
- **48px minimum target proportions.** Every interactive plate, chip, and badge is proportioned so the smallest target implies ≥48×48px at delivery scale, with generous internal padding.
- **Text zones are declared contrast voids.** Button labels, the card thumbnail window, the verdict cartouche, filter-chip labels, the player name — all are explicit reserved voids (bone-neutral field + hairline keyline so live content meets contrast). We bake NO mock text except the three licensed verdict specimens on V3.
- **Reduce-motion is honored at the source:** every state is a *static truth*. No state depends on animation to be legible — the "molten pour" is a static inset+bead geometry cue, not a required animation (Breath, Not Blink: any hover breath is ≥2s and always ships this static variant).
