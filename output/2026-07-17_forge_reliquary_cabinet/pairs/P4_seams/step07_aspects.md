### V1 — THE CANONICAL 5-STATE STRIP  *(the reference truth)*
**Axes moved:** A = all-five-in-sequence · B = orthographic strip. *(both axes at their "survey" pole; the baseline all others are measured against)*
The same crack-map five times, left→right, dormant → waking → lit-lattice → molten → cooled-bronze, in five equal orthographic cells on one knockout field. This is the developer's and the atlas's ground-truth: the ladder proven in one glance, each cell slicing out as a clean textless overlay. Reads as a filmstrip of one seam *learning it was loved.*
- **Role:** master reference + the five shippable state overlays (sliced from the cells).
- **Resolution:** 1536×1024 (landscape, five cells across).
- **Tones (4):** velvet-black · brass-lemon gold · blue-white molten leak · matte umber-bronze.
- **Void:** each cell's interior area behind the seam is transparent (the seam is the only content).

### V2 — THE LIT-LATTICE CORNER SET  *(focus ring for rectangular UI)*
**Axes moved:** A = one-state-isolated (lit-lattice / state 3 only) · B = corner-bracket kit. *(two axes; carrier changes from strip to a 4-corner focus frame)*
State 3 alone, decomposed into four L-bracket corner pieces (top-left, top-right, bottom-left, bottom-right), each a thick cross-linked mesh elbow, positioned at the four corners of the sheet with a large empty center. Drop these on any rectangular card/button/panel and the game gets a gold-lattice *focus cage* — the accessibility focus ring as brand mark (Flair #10, the seam is the signature). The empty center is the declared live-content window.
- **Role:** the reusable focus-ring corner kit for all rectangular chrome.
- **Resolution:** 1024×1024 (square; corners map to corners).
- **Tones (2–3):** velvet-black · brass-lemon gold · (a cooler gold-white highlight on the mesh crowns).
- **Void:** the entire center rectangle is transparent (≥40% of frame) — where the thumbnail/label lives.

### V3 — THE MOLTEN BEAD MACRO  *(the pressed moment, frozen)*
**Axes moved:** A = one-state-isolated (molten / state 4 only) · B = macro crop. *(two axes; extreme optical close on a single state)*

The tempera craquelure lip is sharp at this scale; a single micro-spark (Flair #2, the second ember) sits where the bead's heat has re-lit an old hairline. A frozen photograph of motion (Flair #5).
- **Role:** hero macro / the pressed-state key art / loading-shimmer still.
- **Resolution:** 1024×1024 (square macro).
- **Tones (3–4):** velvet-black · molten brass-gold · blue-white core · dry tempera-cream lip.

### V4 — THE COOLED-BRONZE FULL-WRAP  *(the visited vessel)*
**Axes moved:** A = one-state-isolated (cooled-bronze / state 5) · B = vessel-silhouette wrap. *(two axes; carrier becomes a whole vessel)*
The cooled-bronze seam network wrapping a single reliquary-vessel silhouette (a hinged casket-orb, lid slightly ajar — Flair #1), medium-gauge matte continuous bronze tracing and crossing the form. The vessel body and its interior window are transparent voids (the frame/game shows through); only the bronze wrap is drawn. One junction holds a faint ember-memory (Flair #13, cooled bronze remembers); one seam detours around a keyhole where a low ember-eye watches (Flair #15, one mischief per vessel); one span is worn smooth and bright where a thumb has passed a thousand times (Flair #4, the custodian's thumbprint). This is the game you played yesterday — warm, remembered, unashamed.
- **Role:** the visited/benched vessel treatment + proof that the overlay wraps a real silhouette.
- **Resolution:** 1024×1536 (portrait; a vessel stands taller than wide).
- **Tones (3):** velvet-black · matte umber-bronze · faint warm ember-memory glow.
- **Void:** the vessel interior window + body are transparent; the ajar-lid gap is a declared quiet zone.
