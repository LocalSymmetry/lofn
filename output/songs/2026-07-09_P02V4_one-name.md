# One Name
*(the line you'd cross for one person only)*

## MUSIC PROMPT (Suno style — 946 chars)
Tender-to-cathartic emo-punk in Drop-D, opening almost clean at 184 BPM before the cracked-amp band arrives. A youthful androgynous-female cry-vox starts bare and close — nasal, breath audible, a dying-tape flutter — over a single cassette-wow guitar, listing all the lines it would never cross for anyone, then finding the one exception: one name. As the vow turns, palm-muted chug opens to ringing chords; a circuit-bent eight-bit snare-rim crunches in; field-recorded wheel-grind and an all-ages gang-shout swell like a group-hug, not a brawl. A gated half-bar of breakcore flinches every eight bars and snaps shut. At the one name — too precious to bark — the whole band cuts to true silence, one breath, the name unspoken; then the list resumes, and the reveal lands: every other line held was the same love, aimed wider. Midwest-emo warmth, power-pop lift, breakcore nerve, restraint over excess, rink-reverb slap-back on the falsetto only.
