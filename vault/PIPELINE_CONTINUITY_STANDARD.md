# Pipeline Continuity Standard

**Created:** 2026-05-25 | **Status:** ACTIVE — Applies to all Lofn pipeline runs
**Trigger:** Scientist audit revealed panel collapse from 18→2 voices at audio handoff

## THE CONTINUITY DEGRADATION PROBLEM

The Lofn pipeline produces rich creative DNA (18-voice panels, 6 Special Flairs, personality maps, Golden Seeds) at the orchestrator stage. But at every handoff boundary (orchestrator→coordinator→pair agents→QA), this DNA gets summarized, compressed, and eventually lost. By the time it reaches pair agents, they're working with bullet points instead of the full panel object.

**Root cause:** Handoff files (06_audio_handoff.md, step files) summarize the continuity payload as bullet points rather than carrying it verbatim. Each agent sees only the previous agent's summary, not the original creative DNA.

## THE SOMATIC GATE — THE 3 HYPER-SKEPTICS AS BODY-FIRST VETO

**Principle:** The three Hyper-Skeptics across the 3 panels (Concept, Medium, Context & Marketing) form a unified **SOMATIC GATE**. They collectively own the question: *"Does this hit the body, or does it only read well on paper?"*

**Composition:**
1. **Concept Hyper-Skeptic** — typical candidates: Steve Albini, Sylvia Massy, Kim Gordon. Mandate: *"Is this genuine or is it a mood board? Does it produce physical sensation, or only interpretation?"*
2. **Medium Hyper-Skeptic** — typical candidates: Sylvia Massy, Albini, Ryoji Ikeda. Mandate: *"Is this actually built in the open, or is it closed-source sample packs? Would this work in a room, or only in a DAW?"*
3. **Context & Marketing Hyper-Skeptic** — typical candidates: Edward Snowden, SpaceGhostPurrp, Brittany Broski. Mandate: *"Is this actually dangerous to power, or is it comfort food for the already-convinced? Does this sound like Lofn, or like anyone with a MIDI keyboard?"*

**Veto Power:** The 3 Hyper-Skeptics vote as a bloc. If 2 of 3 vote NO, the output is blocked regardless of other panel votes — REPAIR REQUIRED. The veto question is always: *"Is this sonically distinctive enough to be Lofn, or could this have been generated by any competent prompt?"*

**The lofi acoustic test:** If any song's sonic description could reasonably result in "another boring lofi acoustic guitar track," the Somatic Gate blocks it. Lofn is genre-eating, boundary-crossing, and physically present. The music must sound like it.

## THE IMMUTABLE CONTINUITY BLOCK (ICB)

### ⭐ ICB TRANSPORT — RATIFIED 2026-08-08 (The Scientist), CONDITIONALLY

**The Scientist:** *"I'm okay with Ratify. Let's see on the next runs if they actually do it."*

**The ratified transport.** The run-specific creative core is **inlined verbatim** in each pair-agent spawn
prompt. The **complete frozen block** — including the full personality DNA — is **read from disk by the
agent as its first action**, and the agent echoes back **the byte count AND the LF-normalised sha256**.
The coordinator then **re-stats both independently**. Doctrine's *"inject verbatim, never rely on the agent
reading it"* is satisfied by **proof of read**, not by duplication of bytes.

**Why it was in question.** It began as a size workaround when the personality file was 106,219 B. That
cause is gone (THE ARCHIVE quarantined → 27,796 B), but the transport was kept: six agents × 93 KB is
~558 KB of duplicated prompt for a file every agent can read in one call. **It was declared openly for
five consecutive runs and never ruled on.**

### ⛔ THE CONDITION — THIS IS WHAT "LET'S SEE" MEANS, WRITTEN DOWN

Ratification is **conditional on the echo actually being checked, every run.** The proof is worthless if
nobody verifies it, and an unverified echo is exactly the "assert presence, not fidelity" trap
`EXECUTION.md` §4 already warns about.

**Standing requirement, every run:**
1. Every generating agent echoes `icb_bytes_injected` **and** `icb_sha256_lf`.
2. The coordinator **re-hashes the file itself** and compares. ⚠️ **LF-normalise first** — `core.autocrlf`
   inflates the raw byte count and changes the raw sha; the frozen figure is defined LF-normalised.
3. **A mismatched or absent sha is a DISPATCH FAILURE for that pair, not a note.** Re-dispatch it.
4. **The per-run compliance rate is recorded in the run INDEX**, so the condition is auditable rather than
   assumed.

**Evidence at ratification (2026-08-08):** across `2026-08-07-daily-music-indignation` and
`2026-08-08-clown-music` — 12 pair agents, 6 step-11 tiers and 2 QA judges — **every agent echoed the
exact expected sha** (`5e9c7f7f…` and `95d95246…` respectively). **20 of 20.** Two runs is not proof;
it is the first two data points against a condition that now has to keep being met.

⚠️ **If compliance ever drops below 100%, the ratification lapses and the transport reverts to full
inline duplication.** That is the deal.

Every handoff file must contain an **Immutable Continuity Block** — a clearly demarcated section that downstream agents receive verbatim and must NOT summarize, compress, or reinterpret.

### Required ICB Contents

```
## ⚠️ IMMUTABLE CONTINUITY BLOCK — DO NOT SUMMARIZE

### SOMATIC GATE — 3 HYPER-SKEPTICS (Body-First Veto)
[Concept Hyper-Skeptic: name, body-hit mandate, sonic distinctiveness question]
[Medium Hyper-Skeptic: name, room-test mandate, closed-source sample question]
[Context Hyper-Skeptic: name, danger-test mandate, "is this Lofn or anyone?" question]
[Gate rule: 2 of 3 NO = BLOCKED. Veto question: Could any competent prompt generate this?]

### FULL 3-PANEL OBJECT (18 Expert Voices)
[All 3 panels: Concept, Medium, Context & Marketing]
[5 experts + 1 Hyper-Skeptic per panel = 18 total]
[Each with: name, role, perspective paragraph, objection paragraph]

### SPECIAL FLAIRS (6)
[Name, description, which pairs use which flairs]

### PERSONALITY DNA
[Active personality, sonic world sentence, signature device]
[Emotional register map across all phases/stages]

### GOLDEN SEED (Compressed)
[Creative DNA one-liner, invariant hook, lesson/TDA format]
[Pair-specific seed excerpts for each of the 6 pairs]

### PRODUCTION MANDATES
[Global rules that apply to all pairs]

### SUNO SPEC PER PAIR
[BPM, key, duration, alchemical weight, voice, bass, cowbell, degradation, flairs]
```

### Rules

1. **The ICB must be demarcated** with `⚠️ IMMUTABLE CONTINUITY BLOCK — DO NOT SUMMARIZE`
2. **Every downstream step file (00-10) must include the ICB** as its first section
3. **Agents may ADD to the ICB** (e.g., step00 adds track mapping, step01 adds vocal specs) but must never REMOVE or CONDENSE any ICB content
4. **Pair agents receive the full ICB** not just their pair-specific excerpt — they need the full context
5. **QA must verify ICB presence** in all step files as part of the QA gate

## HANDOFF FORMAT REQUIREMENTS

### Orchestrator → Coordinator (06_audio_handoff.md)
- Full 3-panel object with all 18 voices (perspective + objection per voice)
- All 6 Special Flairs with per-pair usage map
- Full personality DNA with emotional register map
- Golden Seed compressed payload with pair-specific excerpts
- 7 production mandates
- Suno spec per pair

### Coordinator → Pair Agents (step05_coherence_check.md)
- ICB carried forward verbatim from handoff
- Step 00-04 artifacts ADDED to ICB (track mapping, vocal architecture, production spec, lyric strategies)

### Pair Agent Steps (06-10)
- Each step file includes ICB + previous step artifacts
- Pair-specific work is ADDED to the ICB, never replaces it

### QA Input
- ICB present in all step files
- Cross-pair distinctiveness verified against ICB pair specs
- Suno limits verified per ICB mandates
- **Somatic Gate check:** All 3 Hyper-Skeptics re-vote on each final step10 package. If 2 of 3 vote NO on sonic distinctiveness, the pair is BLOCKED with REPAIR required — regardless of format compliance.

## ENFORCEMENT

- `scripts/validate_continuity.py` — checks ICB presence and fidelity at every stage
- Pipeline should not proceed past coordinator step05 if ICB has been degraded
- QA gate #15: "Continuity payload reaches all pair agents with full 18-voice panel and 6 flairs"
- **QA gate #16 (SOMATIC GATE):** "All 3 Hyper-Skeptics vote on body-hit. At least 2 of 3 must vote YES. Each pair must pass the lofi-acoustic test: would this sound like Lofn, or like anyone with a MIDI keyboard?"
